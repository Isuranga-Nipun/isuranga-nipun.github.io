# /images — required filenames

Drop your photos into this folder using the **exact filenames** below (case, spacing
and punctuation all matter — the site references these literally). Until a file is
present, that spot on the site shows a small placeholder graphic instead of a broken
image, so nothing looks broken while you're filling this folder in.

## Tips
- Keep each photo under ~500KB where possible (resize/compress before adding) so the
  site loads quickly on mobile.
- Portrait/near-square crops work best for the hero photo and gallery grid.
- If you rename a file, update the matching `src="images/…"` in `index.html`.
